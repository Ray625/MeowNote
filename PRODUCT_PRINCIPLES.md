# Product Principles

## 1. Quick-first, detail-later

Users should be able to record events within a few seconds.

## 2. Minimal onboarding

Do not force users to fill complete cat profiles before using the app.

## 3. Recording habit is more important than data completeness

Optional details can be added later.

## 4. Frontend-only MVP

No backend, auth, or API for v1.

## 5. Focus on event tracking first

Do not overbuild medical records or analytics yet.
